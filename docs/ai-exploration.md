# AI-assisted repository exploration

The portfolio can be reviewed directly on GitHub or cloned locally for deeper technical inspection.

A coding agent can be useful for navigating a larger repository, tracing dependencies and comparing implementations across projects.

## Suggested workflow

1. Clone the repository.
2. Open the repository in the development environment of your choice.
3. Allow the coding agent to read `AGENTS.md`.
4. Ask questions against the actual project files.

Useful examples include:

- Find all completed projects involving optimization.
- Which projects use FastAPI, and what responsibility does it have in each one?
- Explain a selected project for a non-technical stakeholder.
- Explain the same project for a data engineer.
- Trace the data flow from source to decision output.
- Identify where human approval is required before an automated action.
- Compare the deployment environments of two projects.
- Show how a public synthetic dataset maps to the documented source structure.

The purpose is inspection, not replacement of the project documentation.
