# Example evidence

This folder contains the public evidence for SC-30.

## Inputs

`inputs/frame_manifest.json` describes a representative image frame and the expected operational context.

## Outputs

`outputs/detections.json` shows the structured detector output after confidence and stream mapping.

## Logs

`logs/inference.log` shows the high-level execution trace.

## Visual

`visuals/result.svg` summarizes class-level model performance, inference behaviour and the decision pipeline.

The repository intentionally does not fake a camera screenshot. The visual focuses on the measurable technical evidence of the system.
