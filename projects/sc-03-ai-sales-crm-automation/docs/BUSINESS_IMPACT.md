# Business impact

A sales-operations system that scores inbound activity, prepares follow-ups and keeps CRM actions controlled.

## Operating impact

1. Prioritize leads using consistent scoring rules and model signals
2. Reduce manual CRM updates and follow-up preparation
3. Keep the salesperson in control before high-impact customer communication
4. Create a measurable path from inbound signal to next action

## Decisions supported

The implementation is designed to make the following questions easier to answer and act on:

- How is **qualified lead response time** changing?
- How is **manual touches per lead** changing?
- How is **follow-up completion rate** changing?
- How is **salesperson approval rate** changing?
- How is **pipeline coverage** changing?

## Example operating scenario

An inbound lead requests pricing. The system enriches CRM context, calculates priority, drafts the next action and waits for salesperson approval before updating the deal.

## Measurement

The public example exposes measurable technical and operating indicators without claiming production impact that has not been measured in a live organization.

Relevant KPIs include:

- qualified lead response time
- manual touches per lead
- follow-up completion rate
- salesperson approval rate
- pipeline coverage
