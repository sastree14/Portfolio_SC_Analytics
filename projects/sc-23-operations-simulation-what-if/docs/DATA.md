# Data

## Public data scope

Representative arrival rates, service-time distributions, resource capacity and simulation replications.

## Data principles

- public values are safe to publish
- identifiers do not correspond to real client entities
- schema and relationships are documented where they matter to the workflow
- model or optimization inputs are kept separate from outputs
- timestamps, status fields and audit records are preserved when the process depends on them

## Validation

The technical layer contains the relevant schema checks, SQL, tests or model validation logic for this project.

## Confidentiality

No production credentials, private endpoints or confidential client extracts belong in this repository.
